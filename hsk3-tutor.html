A vanilla-JS port of my React drill app, rebuilt without a framework so it runs on this static site. The card is a tian-zi-ge (田字格) — the crosshair practice square Chinese schoolchildren write characters on — and the palette is qinghua blue-and-white porcelain, where the language and the pottery habit meet. Progress is remembered on this device only. Built for my own studying first, which is the only quality bar a study tool actually answers to.
